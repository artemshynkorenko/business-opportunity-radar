# Kiro Workflow

For non-trivial tasks:

1. Inspect the repository and relevant docs.
2. Restate the requested goal and constraints.
3. Identify affected files.
4. Check the relevant spec before implementation.
5. Implement incrementally.
6. Add or update deterministic tests.
7. Run tests and type checks.
8. Inspect the final diff.
9. Report files changed, decisions, tests, and limitations.
