# Business Opportunity Radar

A private, non-commercial, read-only personal information discovery and organization tool.

## Purpose

The application helps a single user discover and organize publicly available discussions on Reddit and other public platforms.

The initial use case is identifying discussions that may be relevant to the user's personal interests, including:

- business needs and operational problems
- partnerships
- market-entry questions
- manufacturing and sourcing
- automation opportunities
- emerging trends

## Reddit usage

The Reddit integration is read-only and uses the official Reddit Data API.

The application does not:

- post
- comment
- vote
- send messages
- moderate
- contact Reddit users
- modify Reddit content

Retrieved content is filtered, classified, and organized for personal reading and information discovery.

## AI processing

AI may be used to classify and organize individual pieces of retrieved content.

Reddit content is not used to train or fine-tune an AI/ML model.

## Users and distribution

The application is operated by a single user for personal use.

It is not offered to third parties, monetized, or provided as a commercial service.

## Data handling

The application is intended to respect applicable Reddit API policies, access controls, rate limits, and data deletion requirements. It does not use scraping, browser automation, or undocumented Reddit endpoints.

## Status

Early development / prototype.

The repository will contain the implementation of the external read-only discovery workflow.
